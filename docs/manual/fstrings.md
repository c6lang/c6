# 字符串插值 `f"..{expr}.."`

> **状态**：现行规范（`C6_EXT` + `.c6` 后缀） · **索引**：[文档索引](../README.md) · **实现状态**：[status.md](../history/status.md)
>
> `f".."` 是零分配的栈缓冲插值，`@f".."` 产出托管字符串；格式说明与类型检查在编译期做。
>
> 相关：示例 `examples/fstr_demo.c6`、`examples/freestanding_fstr.c6`；用例 `tests/fstr.c6`

## 字符串插值 `f"..{expr}.."`

```c
int n = 42;
const char *s = "abc";
char[:] m = "hello";

const char *a = f"n={n}";              /* "n=42"，类型是 const char * */
const char *b = f"[{s}] [{m}]";        /* "[abc] [hello]"，切片不带结尾的 0 */
const char *c = f"{{}} {n}";           /* "{} 42"：{{ }} 是字面花括号 */
const char *d = f"{(n > 0) ? \"pos\" : \"neg\"}";  /* 表达式里的引号要写 \" */
const char *e = f"{n;08x} {s;8}";      /* 格式说明：宽度、补零、进制、对齐 */
@char keep = @f"saved {n}";            /* 托管版本：结果是一个 @char 对象 */
printf("%s %s\n", f"{n}", keep);        /* 也可以直接当实参用掉 */
```

`f".."` 把字面文本和插值拼起来。每个插值可以带一个**格式说明**，写在
`;` 后面（`;` 不会出现在 C 的表达式里，所以不会和三元运算符的 `:` 打架）：

```c
f"n={n;08x}"        /* 0000002a：宽度 8、补零、十六进制 */
f"[{s;10}]"         /* 右对齐到 10 列 */
f"[{s;-10.3}]"      /* 左对齐、最多 3 个字节 */
```

格式说明是 `[flags][width][.precision][conv]`，和 printf 同一套写法：

| 部分 | 取值 | 含义 |
|---|---|---|
| flags | `-` `0` `+` `#` | 左对齐 / 补零 / 整数总带符号 / 加进制前缀（`0x`、`0`、`0b`） |
| width | 十进制 | 最少占几列（不够用空格补，带 `0` 时用零补） |
| `.precision` | 十进制 | 整数：最少位数；文本：最多几个字节 |
| conv | `d` `i` `u` `x` `X` `o` `b` `c` `s` `p` | 十进制 / 无符号 / 十六进制 / 八进制 / 二进制 / 按字符 / 按文本 / 按指针 |
| conv（浮点） | `f` `F` `e` `E` `g` `G` | 定点 / 科学计数法 / 两者里较短的那种（默认） |

规则：

- 不写 conv 就按插值的静态类型选（上表的默认行为）；写了 conv 就按它来，
  `u` `x` `X` `o` `b` 把值**当无符号**看（`f"{-5;x}"` 是
  `fffffffffffffffb`，与 printf 一致），`d`/`i` 保留符号；
- `c` 把整数当成一个字节印出来，`s` 把值当文本（`char`、`int` 都行）；
- 文本类型（`char *`、`char[:]`、`@char`）只接受 `s` 或不写，别的 conv 是
  编译错误；指针只接受 `p`/`x`/`X`；浮点、结构体仍然不能插值（C84）；
- 宽度和精度的上限都是 1023，超了报错；`;` 只能出现一次（语句表达式里的
  `;` 会被当成格式说明的分隔符，所以直接报错）；
- 浮点：不写 conv 时等价于 `%g`（6 位有效数字，去掉结尾的零），`f` 定点
  （默认 6 位小数）、`e` 科学计数法、`g` 较短的那种；`.precision` 对 `f`/`e`
  是小数位数、对 `g` 是有效数字位数；`u`/`x`/`o`/`b` 这些整数 conv 用在浮点上
  是编译错误；
- 浮点的十进制数字是运行时自己算的（libtcc1 里没有 libc，C99 后端用的是同一
  段代码），常见范围是精确的；需要全部 17 位有效数字时最后一位可能和宿主
  `printf` 不同，舍入是「四舍五入」而不是 `printf` 的「四舍六入五成双」；
  `|v| >= 1e19` 按科学计数法输出；
- `@f".."` 里的格式说明一样管用（拼好之后再打包成托管对象）。

| 插值的类型 | 输出 |
|---|---|
| `char` / `signed char` / `unsigned char` | 字符本身；要数值写 `{(int)c}`。字符常量 `'A'` 在 C 里是 `int`，所以插它得到 `65` |
| `short` / `int` / `long long`（含有无符号）、`enum` | 十进制 |
| `_Bool` | `true` / `false` |
| `const char *`、`char[N]`、`char[:]`、`@char` | 文本（空指针输出 `(null)`） |
| 其他指针 | `0x...`（空指针 `0x0`） |
| `float` / `double` / `long double` | `%g` 那样：`1.5`、`3.14159`（`long double` 按 `double` 打） |
| 其他类型（结构体、函数本身、非字符切片…） | 编译错误 C84 |

规则：

- `f".."` 的结果是**借用**：文本放在当前嵌套深度的临时缓冲里，一直有效到
  "同一个深度的下一次 `f".."` 求值"为止。留住它就写 `@f".."`（托管，生命
  周期跟着引用走），否则当场用掉（`printf`、`strlen`、传参）；
- **注意**：同一个完整表达式里的两个 `f".."` 用的是同一块缓冲，后一个会
  覆盖前一个：

  ```c
  printf("%s %s\n", f"a", f"b");   /* 打出 "b b"，不是 "a b" */
  ```

  要两个结果同时活着就写 `@f".."`（或者分两条语句、各自当场用掉）；
- `@f".."` 的结果是 `@char`：计数为 1 的普通托管对象，可以存进 `@char`、
  `shared @char`（计数是原子的）、`own @char`，也可以当普通 `const char *`
  读；长度由对象头记录，`__c6_str_len(p)` 直接可用；
- 插值是任意表达式，各段从左到右求值且只求值一次：
  `f"{i++}{i}"` 是 `"01"`；
- `{{` / `}}` 输出字面的 `{` / `}`；单个 `}` 是普通字符；`{` 必须有配对的
  `}`（缺了报 C86）。表达式里的引号要转义成 `\"`，因为 f".." 本身是一个
  字符串字面量；
- 嵌套直接写：`f"a{f\"b{n}c\"}d"`（内层引号加 `\`），每深一层多一个 `\`；
  嵌套的每一层有自己的缓冲，互不覆盖；
- 转义与普通字符串一致：`\n`、`\t`、`\"`、`\\`、`\x41`、`\101` 都可用，
  并且只有 `{{`/`}}` 是花括号的转义（普通字符串里没有这一条）；
- `f".."` 不是常量表达式：不能出现在文件作用域或 `static` 局部的初始化式里
  （C85）；`@f".."` 也一样（它要分配对象）；
- 插值里不能用 `try`：错误路径会从函数里返回，运行时的构造器就留在栈上了
  （要写 `int v = try f(); f"x{v}"`）；`;` 只用来引入格式说明，出现第二次
  就报错（C88）；
- `return err(id, f"..")` 的消息会**复制**一份（消息常常是这一帧里的借用缓冲），
  上限 511 字节，更长的部分被截断；
- `__FILE__`、`__LINE__`、`__COUNTER__` 在插值里取到的是真实位置；插值里的
  诊断也报在源文件的行上；
- 只有 c6 的翻译单元（`.c6`）里 `f"` 才被认成 f-string：其他模式下 `f"x"` 仍是"标识符
  f 跟着一个字符串字面量"，语法与原来完全一样；
- 宏里可以写：宏体、宏实参、`#x` 字符串化都会带着原始文本走：

  ```c
  #define TAG f"tag"
  #define ECHO(x) printf("%s\n", x)
  ECHO(f"n={n}");                  /* 可以 */
  printf("%s\n", #f"a{n}");        /* 打出 f"a{n}" */
  ```

  但**宏形参**在插值里不会展开（插值的表达式是在宏展开之后才送进预处理器
  的）：`#define M(n) f"x{n}"` 里的 `{n}` 找不到 `n`。需要时先落成变量，或
  把值从宏里传成实参：`#define M(v) f"x{v}"` 同样不行，写 `#define M(v) ({ int
  __v = (v); f"x{__v}"; })` 这类形式，或干脆不用宏。

实现方式是编译期把 `f".."` 拆成「字面片段 / 插值」交替的 token 流，再逐段
发运行时构造器调用（`__c6_fmt_beg` → `__c6_fmt_l`/`__c6_fmt_i`/… →
`__c6_fmt_end`）。构造器栈按嵌套深度分槽、每线程一份，所以嵌套、递归和循环
都不会互相踩；C99 后端把同一串调用原样翻成 C（`tcc/c99-rt.inc` 里有一份
等价的 C 实现），两个后端行为一致。

```sh
./tcc/c6 -B tcc -run examples/fstr_demo.c6
```
